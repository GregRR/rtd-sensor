# Ni1000 TK5000

`rtd_sensor.ni1000_tk5000` implements the distinct **Ni1000 TK5000 / Nickel NL
5000 ppm/K** characteristic with **1000 Ω at 0 °C**.

Supported characteristic range: **-60 °C to 250 °C**.

The normalized cubic used by the package is:

```text
R(T) / R0 = 1 + 4.427e-3 T + 5.172e-6 T² + 5.585e-9 T³
```

## Quick use

```python
from rtd_sensor import ni1000_tk5000

resistance_ohms = ni1000_tk5000.celsius_to_resistance(100.0)
temperature_c = ni1000_tk5000.resistance_to_celsius(resistance_ohms)
```

## Not interchangeable with Ni1000 6180

`rtd_sensor.ni1000` uses the former DIN / Nickel ND characteristic. TK5000 is a
different curve. Choose between them from the sensor's manufacturer
specification, not from the nominal 1000 Ω value.
